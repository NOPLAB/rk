## Download

Download the latest release for your operating system from the [GitHub Releases](https://github.com/NOPLAB/rk/releases) page. Installers are published for Windows, macOS, and Linux.

### System Requirements

- Windows 10/11, macOS 10.15+, or Linux
- A GPU supporting Vulkan, Metal, or DirectX 12
- 4GB RAM minimum

## Building from Source

### Prerequisites

- Rust 1.85 or later (the workspace uses edition 2024)
- Node.js 22 or later
- CMake and a C++ toolchain — the CAD kernel is built from source

On Linux you will also need the Tauri webview and packaging dependencies:

```bash
sudo apt-get install -y \
  libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev \
  librsvg2-dev libxdo-dev libssl-dev build-essential patchelf cmake clang
```

### Build Commands

```bash
# Clone the repository
git clone https://github.com/NOPLAB/rk.git
cd rk/apps/desktop
npm install

# Run the editor
npm run tauri dev

# Build installers for this platform
npm run tauri build
```

The first build compiles OpenCASCADE from source. Expect tens of minutes and
around 1.5 GB under `target/` — after that it is cached.

### Choosing a CAD Kernel

Geometry operations go through a kernel abstraction selected at build time.
OpenCASCADE is the default: it is the only backend that can subtract solids,
so cut extrudes, holes in revolves and STEP import all depend on it.

```bash
# OpenCASCADE, compiled from source (default)
cargo build

# Truck instead — a pure Rust B-Rep kernel, no C++ toolchain needed,
# but it cannot subtract
cargo build -p rk-cad --no-default-features --features truck

# No kernel; sketching only
cargo build -p rk-cad --no-default-features
```

The kernel has to be selected on `rk-cad` itself. Every other crate depends
on `rk-cad` with its default features, so `--no-default-features` at the
workspace level unifies the default straight back on.
