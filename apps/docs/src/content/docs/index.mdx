## What is RK?

RK is a 3D CAD editor built in Rust. Sketch a profile, turn it into a solid, and
keep every step editable — the feature history is the model.

## Features

<CardGrid stagger>
  <Card title="Parametric Sketching" icon="pencil">
    Draw lines, arcs, circles and splines on any plane or on a face of an
    existing solid, then pin the shape down with constraints and dimensions.
  </Card>
  <Card title="Feature-based Modeling" icon="setting">
    Extrude and revolve the regions a sketch encloses, combine them with boolean
    operations, and roll the history back to any earlier step.
  </Card>
  <Card title="Cross-Platform" icon="rocket">
    Runs natively on Windows, macOS, and Linux.
  </Card>
  <Card title="Mesh and URDF" icon="document">
    Import STL, OBJ, DAE and URDF; export URDF for robotics toolchains.
  </Card>
</CardGrid>
